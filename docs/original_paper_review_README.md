# Original-paper tomato maturity review

This review workspace follows the taxonomy in the original manuscript:

- immature-period
- green-maturity-period
- discoloration-period
- maturity-period

The PNG files initially placed directly in tomato_images are all tomato
candidates. Move each reviewed link into exactly one of the four folders above.
If the crop is too occluded, is not a tomato, or its maturity cannot be
determined, move it to unclassifiable instead.

The files are symbolic links to the SAM2 crop output. Moving a link does not
modify the original image, mask, or source candidate manifest. Do not rename
candidate IDs.
