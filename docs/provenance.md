# Imported example provenance

Processing source and the curated minimal sample were imported on 2026-09-09 from the author's existing PRMS panorama demo working tree. This snapshot includes local revisions and should not be equated with a historical remote commit. Original license terms are preserved in LICENSE_DATA_AND_IMPORTED_CODE.

The sample consists of frames 702–714, two model weights, a reference farm map, annotated side views and saved results. Full training images, caches and the duplicate ZIP archive are excluded. `metadata/source_audit.json` describes an earlier broader local corpus, not the exact imported files. `metadata/dataset_manifest.json` is the integrity manifest of this import.

`benchmarks/` contains historical validation records, with model-selection reuse and missing-label limitations. `demo/summary.json` identifies saved-prediction replay, synthetic poses, assumed row geometry, and unverified associations. We have not established that each historical paper figure used these same checkpoints.

The archived preprint remains unchanged in docs/paper. Revised root.tex is included separately and requires the author's existing journal template, references and figure assets to compile. The manuscript and repository explicitly separate historical field demonstrations from this panorama-only package.
